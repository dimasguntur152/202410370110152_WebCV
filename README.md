# Website Portofolio CV - Dimas Guntur Prasetya Sumoro (202410370110152)

Repository ini berisi *source code* untuk Website CV Portofolio pribadi saya. Proyek ini dibuat untuk memenuhi Tugas Mandiri 2.

## 🌐 Live Website
Website ini sudah di-deploy dan dapat diakses secara online melalui Netlify:
👉 **[https://relaxed-kringle-510c6a.netlify.app](https://relaxed-kringle-510c6a.netlify.app)**

## 🛠️ Teknologi yang Digunakan
*   **HTML5:** Untuk struktur halaman yang semantik.
*   **Tailwind CSS (v4):** Untuk desain antarmuka yang modern dan responsif.
*   **JavaScript (Vanilla):** Untuk interaksi seperti menu mobile dan pop-up modal sertifikat.
*   **Library Tambahan:** Font Awesome (ikon) dan AOS (animasi scroll).

## 📂 Cara Menjalankan Secara Lokal
Jika ingin menjalankan proyek ini di komputer:
1. Clone repository ini: `git clone https://github.com/dimasguntur152/202410370110152_WebCV.git`
2. Install dependencies: `npm install`
3. Jalankan Tailwind compiler: `npx tailwindcss -i ./src/main.css -o ./src/output.css --watch`
4. Buka file `src/index.html` di browser.
